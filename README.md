# ☕ Java Object-Oriented Programming Projects

This repository contains a collection of Java applications developed during the **Object-Oriented Programming** course at **Politecnico di Torino** (Academic Year 2025-2026). 

The projects were part of the curriculum for the Bachelor's Degree in **Management Engineering** (Ingegneria Gestionale, L-8), bridging the gap between business logic and software architecture. All projects have been fully validated against the official university test suite, successfully meeting all requirements and edge-case checks.

> 💡 **Language Note:** While this README and the repository structure are in English to be accessible to an international audience, the actual source code, variables, and internal comments remain in Italian as they reflect the original university exam requirements and academic context. The architectural patterns (OOP) and business logic remain universally understandable!

## 📂 Projects Overview

* **[Real Estate Agency](./real-estate-agency):** Management system for a real estate agency's properties and clients.
* **[Warehouse Supply Management](./warehouse-supply-management):** System for handling warehouse inventory and supplies.
* **[Insurance Branches](./insurance-branches):** Administration and data management of insurance company branches.
* **[Database Management](./database-management):** Core operations and structures for a basic database management system.
* **[Car Sharing](./car-sharing):** Fleet management and vehicle booking system for a car-sharing service.
* **[Restaurant Franchising](./restaurant-franchising):** Management of operations and data across a chain of restaurants.
* **[Airlines Management](./airlines-management):** Flight and passenger management system for an airline company.
* **[Condominium Management](./condominium-management):** Administration software for condominium buildings and facilities.
* **[E-Commerce](./e-commerce):** Core logic and data modeling for an online e-commerce platform.
* **[Museum Management](./museum-management):** Operational management system for a museum's resources.
* **[TV Schedule Management](./tv-schedule-management):** Organization and management of television broadcasting schedules.
* **[Stadium Management](./stadium-management):** Operations and management system for a sports stadium.
* **[Professional Network](./professional-network):** System modeling connections and data within a network of professionals.
* **[Pool Reservations](./pool-reservations):** Booking and reservation system for swimming pool facilities.
* **[School Substitute Management](./school-substitute-management):** Assignment and management of substitute teachers across schools.
* **[Medical Clinic](./medical-clinic):** Administration and management system for a medical office or clinic.
